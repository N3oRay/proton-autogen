PROTON-AUTOGEN

รันแอปพลิเคชัน Windows บน Linux ด้วย Proton
โดยไม่ต้องตั้งค่า Steam และไม่ต้องปรับแต่งด้วยตนเอง

ตรวจจับ Proton เวอร์ชันที่ดีที่สุดที่มีอยู่โดยอัตโนมัติ
กำหนดค่าสภาพแวดล้อมการทำงาน
โหลดโปรไฟล์เฉพาะของแต่ละแอปพลิเคชัน
และใช้ Wine เป็นทางเลือกสำรองเมื่อจำเป็น

────────────────────────
จุดเด่น
────────────────────────
✓ ไม่ต้องตั้งค่า Steam
✓ ตรวจจับ Proton อัตโนมัติ
✓ รองรับ GE-Proton และ Proton-CachyOS
✓ สลับไปใช้ Wine อย่างชาญฉลาด
✓ โปรไฟล์เฉพาะแต่ละแอปพลิเคชัน
✓ ผสานรวม GameScope, GameMode และ MangoHud
✓ ใช้งานได้กับ Steam, Flatpak และการติดตั้งแบบเนทีฟ
✓ เบาและพึ่งพาแพ็กเกจน้อยที่สุด
