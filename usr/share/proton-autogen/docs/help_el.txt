Οι παρακάτω μεταβλητές είναι προαιρετικές και μπορούν να φανούν χρήσιμες για την αντιμετώπιση προβλημάτων.

SDL_VIDEODRIVER=x11
Αναγκάζει τις εφαρμογές SDL να χρησιμοποιούν το backend X11.

```
Παράδειγμα:
    SDL_VIDEODRIVER=x11 proton-autogen --ux
```

SDL_VIDEODRIVER=wayland
Αναγκάζει τις εφαρμογές SDL να χρησιμοποιούν το εγγενές backend Wayland.

```
Παράδειγμα:
    SDL_VIDEODRIVER=wayland proton-autogen --ux
```

Από προεπιλογή, το SDL επιλέγει αυτόματα το καταλληλότερο backend.
Αυτές οι μεταβλητές προορίζονται για δοκιμές συμβατότητας και αντιμετώπιση προβλημάτων.
