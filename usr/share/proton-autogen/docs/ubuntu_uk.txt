## Необхідні умови

Proton-autogen побудовано на основі кількох існуючих інструментів та діє як оркестратор для спрощення їх встановлення та використання.

Щоб забезпечити повноцінне ігрове середовище Proton, рекомендується встановити такі компоненти:

- Steam
- GameMode
- MangoHud
- ProtonUp-Qt

Встановлення (Ubuntu / Linux Mint)
--------------------------

1. Оновіть систему

sudo apt update && sudo apt upgrade -y

2. Встановіть GameMode

sudo apt install gamemode -y

Параметри запуску Steam:

gamemoderun %command%

3. Встановіть MangoHud

sudo apt install mangohud -y

Параметри запуску Steam:

mangohud %command%

Або використовуйте його разом з GameMode:

mangohud gamemoderun %command%

4. Встановіть ProtonUp-Qt

Якщо Flatpak вже встановлено:

flatpak install flathub net.davidotek.pupgui2

Додатково:
Запустіть ProtonUp-Qt, виберіть Steam та встановіть останню версію Proton-GE.

Переваги
----

- ​​Ігровий режим: Автоматично оптимізує продуктивність процесора під час гри
- MangoHud: Відображає накладання для моніторингу FPS та продуктивності системи
- ProtonUp-Qt: Спрощує встановлення та керування версіями Proton-GE

Після встановлення Proton-autogen може автоматично керувати середовищем Proton та запускати програми Windows.

Рекомендована мінімальна конфігурація:

- ProtonUp-Qt
- Proton-autogen

Інші інструменти є необов'язковими, але дуже рекомендуються для кращої продуктивності та моніторингу.
