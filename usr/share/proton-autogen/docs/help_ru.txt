ПЕРЕМЕННЫЕ ОКРУЖЕНИЯ
━━━━━━━━━━━━━━━━━━━━━━━━━━

Следующие переменные являются необязательными и могут быть полезны
для устранения неполадок.

SDL_VIDEODRIVER=x11
    Принудительно использует бэкенд X11 для приложений SDL.

    Пример:
        SDL_VIDEODRIVER=x11 proton-autogen --ux

SDL_VIDEODRIVER=wayland
    Принудительно использует нативный бэкенд Wayland для приложений SDL.

    Пример:
        SDL_VIDEODRIVER=wayland proton-autogen --ux

По умолчанию SDL автоматически выбирает наиболее подходящий бэкенд.
Эти переменные предназначены для проверки совместимости и устранения неполадок.
