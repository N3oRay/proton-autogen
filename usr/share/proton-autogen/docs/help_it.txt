SISTEMA DEI PREFIX
━━━━━━━━━━━━━━━━━━━━━━━━━━
STEAM_COMPAT_DATA_PATH

--pc        Prefix personalizzato
--pa        Prefix automatico (uno per applicazione)
--ps        Prefix condiviso
default     Prefix principale

Per impostazione predefinita, Proton-Autogen utilizza un prefix condiviso chiamato "main".
Questo è la modalità consigliata per la maggior parte degli utenti perché è semplice e leggera.

Un prefix dedicato per applicazione è raccomandato nei seguenti casi:

- Applicazioni che installano runtime (.NET, Visual C++, ecc.)
- Giochi con anti-cheat o sistemi di protezione sensibili
- Applicazioni che modificano molto il registro di Windows
- Quando un programma danneggia o inquina il prefix principale

Usa --pa per creare automaticamente un prefix isolato per un'applicazione.

VARIABILI D'AMBIENTE
━━━━━━━━━━━━━━━━━━━━━━━━━━

Le seguenti variabili sono opzionali e possono essere utili per la risoluzione dei problemi.

SDL_VIDEODRIVER=x11
Forza le applicazioni SDL a utilizzare il backend X11.

```
Esempio:
    SDL_VIDEODRIVER=x11 proton-autogen --ux
```

SDL_VIDEODRIVER=wayland
Forza le applicazioni SDL a utilizzare il backend Wayland nativo.

```
Esempio:
    SDL_VIDEODRIVER=wayland proton-autogen --ux
```

Per impostazione predefinita, SDL seleziona automaticamente il backend più appropriato.
Queste variabili sono destinate ai test di compatibilità e alla risoluzione dei problemi.
