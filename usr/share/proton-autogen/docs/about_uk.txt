PROTON-AUTOGEN

Запускайте Windows-програми в Linux через Proton,
без налаштування Steam або ручної конфігурації.

Автоматично визначає найкращу доступну версію Proton,
налаштовує середовище виконання,
завантажує профілі для кожної програми
та використовує Wine як резервний варіант у разі потреби.

────────────────────────
ОСНОВНІ ПЕРЕВАГИ
────────────────────────
✓ Не потребує налаштування Steam
✓ Автоматичне визначення Proton
✓ Підтримка GE-Proton та Proton-CachyOS
✓ Інтелектуальний резервний перехід на Wine
✓ Профілі для окремих програм
✓ Інтеграція GameMode та MangoHud
✓ Сумісність зі Steam, Flatpak та нативними встановленнями
✓ Легкий та мінімалістичний за залежностями
