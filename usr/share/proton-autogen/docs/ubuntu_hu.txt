## Előfeltételek

A Proton-autogen több meglévő eszközre épül,
és összehangoló szerepet tölt be a használatuk egyszerűsítéséhez.

Teljes Proton-környezethez a következők telepítése ajánlott:

- Steam
- GameMode
- MangoHud
- ProtonUp-Qt

Telepítés (Linux Mint / Ubuntu)
----------------------------------

1. A rendszer frissítése

    sudo apt update && sudo apt upgrade -y

2. A GameMode telepítése

    sudo apt install gamemode -y

Steam-beállítás:

    gamemoderun %command%

3. A MangoHud telepítése

    sudo apt install mangohud -y

Steam-beállítás:

    mangohud %command%

Vagy a GameMode-dal együtt:

    mangohud gamemoderun %command%

4. A ProtonUp-Qt telepítése

Ha a Flatpak telepítve van:

    flatpak install flathub net.davidotek.pupgui2

Opcionális:
Indítsa el a ProtonUp-Qt-t, válassza a Steam-et, majd telepítse a Proton-GE legújabb verzióját.

Eredmény:

- GameMode: a processzor teljesítményének optimalizálása.
- MangoHud: az FPS és a rendszerstatisztikák megjelenítése.
- ProtonUp-Qt: a Proton-GE telepítése és kezelése.

Ezeknek az eszközöknek a telepítése után a Proton-autogen automatikusan
kezelni tudja a Proton-környezetet, és el tudja indítani a Windows-alkalmazásokat.

Ajánlott minimális konfiguráció:
- ProtonUp-Qt
- Proton-autogen
