PROTON-AUTOGEN

Запускайте приложения Windows в Linux с помощью Proton, без настройки Steam и ручной конфигурации.

Автоматически определяет наиболее подходящую доступную версию Proton,
настраивает среду выполнения,
загружает профили для конкретных приложений и при необходимости использует Wine в качестве резервного решения.

──────────────────────── ПРЕИМУЩЕСТВА ────────────────────────
✓ Не требует настройки Steam
✓ Автоматическое обнаружение Proton
✓ Поддержка GE-Proton и Proton-CachyOS
✓ Интеллектуальное переключение на Wine
✓ Индивидуальные профили для каждого приложения
✓ Интеграция с GameScope, GameMode и MangoHud
✓ Совместимость со Steam, Flatpak и нативными установками
✓ Лёгкость и минимальное количество зависимостей
