PROTON-AUTOGEN

Run Windows applications on Linux with Proton—
without Steam setup or manual configuration.

Automatically detects the best available Proton
version, configures the runtime environment,
loads per-application profiles, and falls back
to Wine whenever necessary.

────────────────────────
HIGHLIGHTS
────────────────────────
✓ Zero Steam configuration
✓ Automatic Proton detection
✓ GE-Proton & Proton-CachyOS support
✓ Intelligent Wine fallback
✓ Per-application profiles
✓ GameMode & MangoHud integration
✓ Steam, Flatpak & native compatibility
✓ Lightweight and dependency-minimal
