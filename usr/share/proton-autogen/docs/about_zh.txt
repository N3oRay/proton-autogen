PROTON-AUTOGEN

在 Linux 上通过 Proton 运行 Windows 应用程序，
无需 Steam 配置或手动设置。

自动检测最佳可用的 Proton 版本，
配置运行环境，
加载每个应用的专属配置文件，
并在必要时自动回退到 Wine。

────────────────────────
亮点功能
────────────────────────
✓ 无需 Steam 配置
✓ 自动检测 Proton
✓ 支持 GE-Proton 与 Proton-CachyOS
✓ 智能 Wine 回退机制
✓ 按应用配置文件
✓ 支持 GameMode 与 MangoHud
✓ 兼容 Steam、Flatpak 和原生安装
✓ 轻量级、依赖极少
