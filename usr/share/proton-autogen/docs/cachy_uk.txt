# Посібник зі встановлення Proton-CachyOS

## ПЕРЕДУМОВИ

Перед початком переконайтеся, що виконано такі умови:

* Встановлено сумісний дистрибутив Linux (Arch Linux, CachyOS або дистрибутив на базі Arch).
* Встановлено Steam.
* Є активне підключення до Інтернету.
* Є права адміністратора (`sudo`).

---

## СПОСІБ 1 – Встановлення через CachyOS Hello (Рекомендовано)

Це найпростіший і рекомендований спосіб встановлення для користувачів CachyOS.

### Кроки

1. Відкрийте **CachyOS Hello**.
2. Перейдіть до меню **Apps / Tweaks**.
3. Натисніть **Install Gaming Packages**.

Буде автоматично встановлено такі компоненти:

* Steam
* Proton-CachyOS
* MangoHud
* Gamescope
* Heroic Games Launcher
* Lutris
* Необхідні бібліотеки Vulkan

### Перевірка

1. Повністю закрийте Steam, якщо він уже запущений.
2. Запустіть Steam знову.
3. Перейдіть до:

```text
Steam
└── Налаштування
    └── Сумісність
```

4. Переконайтеся, що **Proton-CachyOS** відображається у списку доступних інструментів сумісності.

---

## СПОСІБ 2 – Встановлення за допомогою Pacman

Якщо ви бажаєте встановити компоненти вручну, скористайтеся Pacman.

### Встановлення ігрових пакетів

```bash
sudo pacman -S cachyos-gaming-meta
sudo pacman -S cachyos-gaming-applications
```

### Встановлення лише Proton-CachyOS

```bash
sudo pacman -S proton-cachyos-slr
```

### Примітка

Рекомендується використовувати варіант **Proton-CachyOS-SLR** (Steam Linux Runtime).

Він забезпечує кращу сумісність з іграми, що використовують системи захисту від шахрайства, такі як **Easy Anti-Cheat (EAC)** та **BattlEye**.
