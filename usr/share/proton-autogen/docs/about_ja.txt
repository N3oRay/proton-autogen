PROTON-AUTOGEN

Proton を使って Linux 上で Windows アプリケーションを実行。
Steam の設定も手動での調整も不要です。

利用可能な最適な Proton バージョンを自動的に検出し、
実行環境を構成し、
アプリケーションごとのプロファイルを読み込み、
必要に応じて Wine を代替手段として使用します。

────────────────────────
主な特長
────────────────────────
✓ Steam の設定は不要
✓ Proton を自動検出
✓ GE-Proton と Proton-CachyOS に対応
✓ Wine へのスマートな自動切り替え
✓ アプリケーションごとのプロファイル
✓ GameScope、GameMode、MangoHud との統合
✓ Steam、Flatpak、ネイティブインストールに対応
✓ 軽量で依存関係が最小限
