# Руководство по установке Proton-CachyOS

## ПРЕДВАРИТЕЛЬНЫЕ ТРЕБОВАНИЯ

Перед началом убедитесь, что у вас есть следующее:

* Совместимый дистрибутив Linux (Arch Linux, CachyOS или производный от Arch).
* Установленный Steam.
* Активное интернет-соединение.
* Права администратора (`sudo`).

---

## МЕТОД 1 – Установка через CachyOS Hello (рекомендуется)

Это самый простой и рекомендуемый способ установки для пользователей CachyOS.

### Шаги

1. Откройте **CachyOS Hello**.
2. Перейдите в раздел **Apps / Tweaks**.
3. Нажмите **Install Gaming Packages**.

Следующие компоненты будут установлены автоматически:

* Steam
* Proton-CachyOS
* MangoHud
* Gamescope
* Heroic Games Launcher
* Lutris
* Необходимые библиотеки Vulkan

### Проверка

1. Полностью закройте Steam, если он уже запущен.
2. Снова запустите Steam.
3. Перейдите в:

```

Steam
└── Настройки
└── Совместимость

````

4. Убедитесь, что **Proton-CachyOS** отображается в списке доступных инструментов совместимости.

---

## МЕТОД 2 – Установка с помощью Pacman

Если вы предпочитаете устанавливать необходимые компоненты вручную, используйте Pacman.

### Установка групп игровых пакетов

```bash
sudo pacman -S cachyos-gaming-meta
sudo pacman -S cachyos-gaming-applications
````

### Установка только Proton-CachyOS

```bash
sudo pacman -S proton-cachyos-slr
```

### Примечание

Рекомендуется вариант **Proton-CachyOS-SLR** (Steam Linux Runtime).

Он обеспечивает лучшую совместимость с играми, использующими системы защиты от читов, такие как **Easy Anti-Cheat (EAC)** и **BattlEye**.
