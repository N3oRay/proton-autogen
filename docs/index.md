# Proton-Autogen Documentation

Welcome to the **Proton-Autogen** documentation.

Proton-Autogen is designed to simplify the process of running Windows applications and games on Linux using Proton and Wine, while reducing the amount of manual configuration required.

## Documentation

### 🚀 Getting Started

- [Installation](install.md) — Install Proton-Autogen on your Linux system.
- [Fedora Installation](fedora-install.md) — Fedora-specific installation instructions.
- [Examples](examples.md) — Practical examples and common usage scenarios.

### ⚙️ Configuration & Architecture

- [Architecture](ARCHITECTURE.md) — Overview of the Proton-Autogen architecture and components.
- [Profiles](profiles.md) — Configure and manage application profiles.
- [Proton Paths](PROTON_PATHS.md) — Understand Proton locations and path configuration.

### 🎮 Running Windows Applications & Games

- [Run EXE on Linux](run-exe-on-linux.md) — Learn how to run Windows `.exe` applications on Linux.
- [Run Windows Games with Proton](run-windows-games-with-proton.md) — Run Windows games using Proton outside a traditional Steam workflow.
- [Proton Without Steam](proton-without-steam.md) — Learn how to use Proton without relying on the Steam client.
- [Proton Prefix Guide](proton-prefix-guide.md) — Understand Proton/Wine prefixes and how they work.
