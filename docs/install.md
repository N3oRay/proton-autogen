AUR package for proton-autogen.

## Install (AUR)

paru -S proton-autogen

## Manual build

makepkg -si

### (install manual)

```bash
git clone https://github.com/N3oRay/proton-autogen.git
cd proton-autogen
chmod +x install.sh
./install.sh
```
### (update manual)
```bash
cd proton-autogen
git pull
chmod +x update.sh
./update.sh
```
