# Sponsoring Proton-Autogen

## Support the project

**Proton-Autogen** is a lightweight, open-source Linux utility that makes running Windows applications and games easier by automatically managing Proton and Wine environments.

It is independently developed and maintained.
Your support helps fund continued development, compatibility improvements, testing, and long-term maintenance — while keeping the project free and open source.

Every contribution, no matter the size, makes a real difference.

---

## Why support Proton-Autogen?

- Keep the project **free and open source**
- Fund active development and new features
- Improve Proton & Wine compatibility
- Support testing across more Linux distributions
- Help maintain packaging (AUR, PPA, Flatpak, etc.)
- Allow more time to be dedicated to the project

---

## Project activity

Proton-Autogen is actively used and discussed in the Linux gaming community (especially CachyOS, EndeavourOS and others).

Current activity (approximate):

- **~2,100** repository clones
- **~500** unique cloners
- Hundreds of downloads via the Ubuntu PPA
- Regular feedback and testing from the community

These numbers show growing interest and real usage.
