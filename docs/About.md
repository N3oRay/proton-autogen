About Proton-Autogen

Proton-Autogen was born from a simple idea: to build the application I always wanted on Linux.

Running Windows applications on Linux has become significantly easier thanks to projects such as Steam, Proton, and Wine. However,
the ecosystem remains fragmented and often overwhelming for new users. Many existing tools expose too many technical concepts too early,
such as compatibility layers, prefixes, and runtime configuration.

Proton-Autogen takes a different approach.

Its goal is to make running Windows applications on Linux as simple as launching a native application, while still providing advanced features for users who need them.

The philosophy behind the project is straightforward:

Complex concepts still exist, but users shouldn't have to understand them just to get started.

Proton-Autogen does not try to replace the existing Linux gaming ecosystem. Instead, it acts as an orchestrator that brings together proven technologies such as:

Steam
Proton
Wine
MangoHud
GameMode
Lutris

Rather than reinventing these tools, Proton-Autogen detects, configures, and launches the appropriate runtime automatically, reducing the amount of manual setup required.

Whether you're launching a game, an installer, or a Windows application, the goal is always the same:

Select the best available runtime automatically
Manage prefixes without user intervention
Apply sensible default configurations
Keep advanced options available without exposing unnecessary complexity

The long-term vision is simple:

Become the tool you recommend to someone new to Linux who simply wants to run a Windows application without spending hours reading documentation or configuring their system.

Proton-Autogen is designed to remove friction—not flexibility.
